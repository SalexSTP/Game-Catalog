# Game Catalog

ASP.NET Core MVC уеб приложение за управление на вътрешен каталог с видеоигри за геймърски клуб.

Проектът е разработен като решение на стажантска задача за каталог с до 250 видеоигри, сортиране по различни критерии, справки и специално правило за заглавието **The Legend of Code**.

## Използвани технологии

- C#
- ASP.NET Core MVC
- Entity Framework Core
- Microsoft SQL Server / LocalDB
- Bootstrap
- Bootstrap Icons

## Структура на проекта

```text
GameCatalog/
├── Common      - константи и общи стойности
├── Data        - DbContext, migrations, repository и seed данни
├── Domain      - основни модели и enum-и
├── Services    - бизнес логика, DTO модели и service интерфейси
└── Web         - MVC controllers, views, view models и UI
```

## Основни функционалности

- Каталог с видеоигри
- Добавяне, редактиране и изтриване на игри
- Търсене в каталога
- Филтриране по жанр, платформа, PEGI и оценка
- Сортиране по:
  - заглавие
  - година на издаване
  - жанр
  - потребителска оценка
  - разработчик
- Комбинирано сортиране по няколко критерия
- Поддръжка на няколко платформи за една игра
- Ограничение до 250 игри
- Смяна на език между английски и български
- Автоматично създаване и зареждане на примерни данни

## Справки

В приложението има отделна страница **Reports**, която съдържа следните справки:

1. Всички игри с оценка над 8.5, подредени по година в низходящ ред.
2. Всички игри за платформа PC, издадени през последните 5 години, сортирани по оценка.
3. Всички игри, подходящи за възраст под 12 години, групирани по жанр.
4. Top 3 игри във всеки жанр, сортирани по оценка.

При сортиране заглавието **The Legend of Code** винаги се показва на първо място, ако присъства в съответния резултат.

## Данни за игра

Всяка игра съдържа:

- Заглавие
- Жанр
- Платформа/и
- Година на издаване
- Разработчик / студио
- PEGI рейтинг
- Потребителска оценка от 1.0 до 10.0

## Автоматично seed-ване

При стартиране приложението автоматично:

1. Прилага наличните EF Core migrations.
2. Проверява дали в базата има игри.
3. Ако базата е празна, добавя примерни игри.

Seed данните включват **The Legend of Code** и достатъчно игри, за да могат всички справки да показват резултати веднага след първото стартиране.

## Стартиране на проекта

### Необходими инструменти

- .NET 9 SDK
- Microsoft SQL Server LocalDB или SQL Server Express
- Visual Studio 2022 / JetBrains Rider / VS Code

### Стъпки

1. Отвори solution файла:

```text
GameCatalog.sln
```

2. Провери connection string-а в:

```text
Web/appsettings.json
```

По подразбиране се използва LocalDB:

```json
"DefaultConnection": "Server=(localdb)\\mssqllocaldb;Database=GameCatalog;Trusted_Connection=True;MultipleActiveResultSets=true;Encrypt=False"
```

3. Стартирай `Web` проекта.

Алтернативно от terminal в root папката на solution-а:

```bash
dotnet run --project Web/Web.csproj
```

4. Отвори приложението в браузър.

По подразбиране launch профилите използват:

```text
https://localhost:7130
http://localhost:5186
```

## Навигация

- **Home** - начална страница с кратка информация и dashboard статистики.
- **Catalog** - каталог с всички игри, търсене, филтриране, сортиране и управление.
- **Reports** - справките, изискани в условието.
- **EN / BG** - смяна на езика на интерфейса.

## Архитектурни решения

Проектът е разделен на няколко слоя:

- `Domain` съдържа основните модели и enum-и.
- `Data` съдържа достъпа до базата, EF Core конфигурацията, repository слоя и seed данните.
- `Services` съдържа бизнес логиката, сортирането, справките и DTO моделите.
- `Web` съдържа MVC частта и потребителския интерфейс.
- `Common` съдържа константи като максимален брой игри, прагове за справки и специалното заглавие.

Authentication и роли не са добавени умишлено, защото не са част от условието. В бъдеща версия могат да се добавят администратори и нормални потребители чрез ASP.NET Core Identity.

## Покритие на условието

- До 250 игри - покрито чрез service проверка.
- Една игра с няколко платформи - покрито чрез flags enum.
- Сортиране по всички изискани критерии - покрито.
- Комбинирано сортиране - покрито.
- Всички изискани справки - покрити в Reports страницата.
- Специално правило за **The Legend of Code** - покрито в service layer-а.
- Данните се съхраняват в SQL Server база чрез Entity Framework Core.
- Визуализацията е реализирана като Bootstrap MVC уеб интерфейс.
